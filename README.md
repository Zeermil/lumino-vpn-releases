# lumino-vpn-releases
Official releases and APKs for Lumino VPN

## Каталоги расширений
- `extensions-v2/` — основной каталог подписанных пакетов `.luminoext` (Ed25519 `lumino-official-v1`) для актуальных версий Lumino VPN.
- `extensions/` — legacy-каталог одиночных `.py` скриптов для обратной совместимости со старыми версиями клиента.
